My current work centers on **CARINA** and **MAYA**: practical AI tools designed around privacy, human control, and reliable execution.

| Project | What it does | Focus |

## How I work

```text
Observe the real system → build the smallest complete change → verify it → document the evidence → repeat
```

- Real integrations over simulated behavior
- Privacy boundaries stated precisely
- Explicit errors, useful logs, and reproducible checks
- Native Swift and macOS tools when they make the system simpler
- Human approval for consequential actions
