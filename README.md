- Human-centered interfaces for complex AI workflows

## Working principles

- Build real, runnable software and describe prototypes honestly.
- Keep sensitive credentials and private state out of source control.
- Make important system behavior visible to the person operating it.
- Treat accessibility, safety, and verification as product features.
